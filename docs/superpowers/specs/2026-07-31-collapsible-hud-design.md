# HUD 展开/折叠功能设计

## 目标

为 Codex 运行监测 HUD 增加展开/折叠功能。折叠后保留顶部标题区、连接状态和剩余用量圆环，隐藏圆环下方的详细信息，并同步缩短 Tauri 窗口高度。

## 交互

- 标题栏右侧新增展开/折叠按钮，并使用箭头图标表达当前状态。
- 展开状态保留现有全部内容。
- 折叠状态保留：
  - 主标题、日期时间和窗口控制按钮；
  - 当前连接状态；
  - 剩余用量百分比圆环。
- 折叠状态隐藏：
  - 模型、套餐、推理强度、速度、用户名和客户端版本；
  - 距离重置和下次重置时间；
  - 刷新、动效及版本号工具栏。
- 展开/折叠状态写入本机 `localStorage`，软件重启后恢复上次状态。

## 窗口行为

- 窗口宽度始终保持 `400px`。
- 展开高度保持 `680px`。
- 折叠高度根据保留区域设置为固定紧凑高度，目标为 `400–420px`，以实际无裁切、无底部大块空白为验收标准。
- Tauri 环境使用窗口 API 调整高度；浏览器预览只切换页面内容，不调用桌面窗口 API。
- 窗口宽度不变，因此折叠和展开时保持当前左上角位置，不影响右上角停靠。

## 动效与错误处理

- 详细信息区使用短时透明度和位移过渡。
- 关闭动效或系统启用 `prefers-reduced-motion` 时不执行过渡。
- 本地状态读取失败时默认展开。
- Tauri 窗口缩放失败时保留界面折叠结果，不导致白屏。

## 测试

- 验证默认展开时显示详细信息和底部工具栏。
- 验证点击折叠后只保留标题区、连接状态和百分比圆环。
- 验证按钮可恢复展开并具有正确的辅助说明。
- 验证折叠状态写入并从本地配置恢复。
- 验证展开与折叠对应正确的窗口尺寸。
- 执行前端测试、TypeScript 检查和生产构建。

## 范围边界

- 不修改数据采集、provider、托盘或自动启动逻辑。
- 不新增 Rust 配置结构或 Tauri command。
- 不改变窗口宽度和现有视觉主题。
